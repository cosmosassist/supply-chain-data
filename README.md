# supply-chain-data

Source workbook for the supply-chain knowledge graph ([cosmosassist/supply-chain-kg](https://github.com/cosmosassist/supply-chain-kg)).

- [Renault source workbook](renault_chain.xlsx) — battery-metals supply-chain research.
- Updates: edit the workbook, commit here; the KG ingest pipeline picks it up as a new dataset version.

## Graph decisions

Start with a [decision packet](decisions/README.md). Record the human decision before opening a pull request for the approved graph change. The knowledge graph project owns PostgreSQL application and the applied ledger.
